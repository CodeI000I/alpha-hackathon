## Хранение и деплой

`backend/coldstart/0008_news_coldstart.sql` содержит замороженные исходные
ID, URL, даты и тексты. SHA-256 входных RSS, количество материалов и SHA-256
SQL сохранены в соседнем manifest. Сырые RSS остаются локально в ignored
`data/coldstart-2026-10-26/`.

Пакет `backend/coldstart` встроен в server/worker. После обычных миграций
вызывается существующий `Store.Migrate`: PostgreSQL advisory lock,
`schema_migrations`, одна транзакция. Сетевого скачивания на старте нет.
Для изолированных установок без архива есть `NEWS_COLDSTART_ENABLED=false`;
по умолчанию включён. Этот флаг не отключает обычный RSS-сбор.
`ON CONFLICT DO NOTHING` сохраняет более свежие версии новостей и завершённые
задания. Недостающие задания для существующих пользователей с компанией и
ролью добавляются в штатную `news_deliveries`.

Регистрация и изменение ролей/профиля охватывают 21 день. `RANK_LOOKBACK`
в коде, Compose и Helm — `504h`; операторское переопределение имеет приоритет.
Снимок статический: при позднем деплое даты не сдвигаются, а обработка выбирает
последние 504 часа на момент запуска.

**Сырые новости и очередь не являются готовыми персональными инсайтами.**
Модель работает через существующий оркестратор после появления профиля.
`RANK_MAX_PER_RUN=20` и период 15 минут сохранены: большая очередь требует
нескольких проходов. Готовые локальные LLM-результаты этот снимок не переносит:
company/news ID в разных БД могут отличаться.

## Повторное формирование

```bash
python scripts/prepare_news_coldstart.py \
  --start 2026-10-05T00:00:00+03:00 --end '<end из manifest>' \
  --feed S077=data/coldstart-2026-10-26/probe-0 \
  --feed S142=data/coldstart-2026-10-26/probe-4 \
  --feed S142=data/coldstart-2026-10-26/retry-1 \
  --feed S142=data/coldstart-2026-10-26/frank-3.xml \
  --feed S142=data/coldstart-2026-10-26/frank-4.xml \
  --feed S142=data/coldstart-2026-10-26/frank-5.xml \
  --feed S142=data/coldstart-2026-10-26/frank-6.xml \
  --output backend/coldstart/0008_news_coldstart.sql
```

Генератор не подключается к сети/БД/LLM. Проверяет домены, даты с часовыми
поясами, категорию Интерфакса, ID, конфликты версий и размер RSS. Защитный HTML
не принимается за RSS. Уже применённый seed не редактируют для обновления
сервера: следующий снимок требует нового уникального имени миграции.

запусков — в `experiments/coldstart_2026-10-26.ipynb`.
