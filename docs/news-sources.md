# Источники новостей демки

Выбор проверен 25 октября 2026 года. После миграции `0007` стандартный набор
состоит из **трёх издателей**, опрашиваемых существующим Go RSS-сборщиком.
Основание — `company_research.xlsx`, лист «3. Источники», и его идентификаторы
в seed-каталоге. Доска Miro в момент проверки не загрузилась; актуальность
копии относительно последних правок доски не подтверждена.

| Приоритет | Источник | Что используем | Граница доверия |
| --- | --- | --- | --- |
| 1 | **Банк России**, S077 | [RSS пресс-релизов](https://www.cbr.ru/rss/RssPress): решения по ставке, регулирование, банковский сектор | Первичный официальный источник для собственных решений ЦБ. Не подтверждает сам по себе влияние на конкретную компанию. |
| 2 | **Интерфакс**, S136 | [RSS](https://www.interfax.ru/rss), только категория `Экономика`: компании, отрасли, деловые события | Редакционное сообщение; заявления компаний, оценки и прогнозы требуют атрибуции. |
| 3 | **Frank Media**, S142 | [RSS](https://frankmedia.ru/feed): банки, финансы, инвестиции | Отраслевое финансовое СМИ, выбранное из группы S142. Это не официальный регулятор и не источник нормативных актов. |

Приоритет задаёт порядок опроса, а `source_class` в `sources.config` фиксирует
категорию происхождения. Это **не вероятность достоверности**, не confidence
модели и не важность новости для компании. Для выводов по-прежнему нужны цитата
из материала и факты из профиля компании. Противоречие с первоисточником нельзя
разрешать простым повышением числового score.

## Путь данных

`sources → Go RSSFetcher → news_items → news_deliveries → /rank → feed_items`.
Для подключения не добавлены новый сервис, парсер HTML или платная модель.
Период опроса остаётся `INGEST_PERIOD` (по умолчанию 15 минут).

Сохраняются исходные URL, source ID, заголовок, RSS-описание и время публикации
с часовым поясом. Для ЦБ и Интерфакса выбран `content_policy=metadata_only`:
описание остаётся summary, а body пуст. У ЦБ описания подробные, у Интерфакса —
короткие анонсы. Для Frank Media сохранено прежнее поведение `feed_content`:
body берётся только из предоставленного RSS поля `content:encoded`/`full-text`.
Это сохраняет уже собранные тексты при повторном импорте. Недостающий текст не
придумывается и страницы статей дополнительно не скачиваются. RSS-анонс не
гарантирует достаточно доказательств для любого вопроса пользователя.

Дополнительные ограничения действуют на уровне кода:

- `article_hosts` допускает только точные HTTPS-домены издателей. Подмена ссылок
  на другой сайт, userinfo, нестандартный порт или fragment не принимаются.
- Для такого источника feed также должен принадлежать разрешённому домену;
  перенаправление на другой origin запрещено. Проверка сертификатов сохраняется.
- Категории Интерфакса фильтруются до разбора отдельных новостей: спорт и общая
  политическая лента не расходуют бюджет анализа.
- Сохраняются предел ответа 8 MiB и 30-секундный HTTP timeout рабочего сборщика.
  Неизвестная дата не заменяется временем загрузки. Отказ источника логируется,
  остальные источники продолжают обрабатываться.

Отдельный Python-парсер `cbr_press` остаётся опциональным и по умолчанию выключен.
Он получает полный HTML и пишет в analytics-хранилище; обратного импорта в
Go-ленту у него нет. Для этой демки включать его параллельно с Go RSS не требуется:
это создало бы второй независимый путь получения тех же публикаций.

## Почему другие кандидаты не включены

Это результаты проверки из среды разработки, а не утверждение о постоянном
состоянии сайтов или их доступности из работающего кластера.

| Кандидат из каталога | Результат 25.10.2026 | Решение |
| --- | --- | --- |
| Росфинмониторинг, S102 | Ошибка проверки TLS-цепочки (`missing issuer`) | Не ослаблять TLS. Отдельно проверить доступ из кластера перед подключением. S102 описывает перечни ПОД/ФТ; публичные новости не заменяют доступ к перечням и проверку контрагентов. |
| БКС, S112 | `robots.txt`: HTTP 403, «Доступ заблокирован» | Не обходить блокировку; отраслевую финансовую тему покрывает Frank Media. |
| Росстат, S080 | Ошибка проверки TLS-цепочки | Не считать подключённым до подтверждения безопасного доступа. |
| Правительство, S085 | HTTPS timeout при проверке robots | Не включать непроверенный HTTP feed. |
| ФНС | Официальный RSS HTTP 200, но 0 публикаций | Не учитывать пустую ленту как рабочий источник. |
| ПРАЙМ, S138 | HTTP 200, 100 публикаций без описания/текста | Одних заголовков мало для этой демки. |
| ТАСС, S137 | `robots.txt`: HTTP 403 | RSS далее не запрашивался. |

Остальные ранее включённые seed-RSS отключаются миграцией только для будущего
сбора. Исторические новости, готовые карточки, очередь и пользовательские
источники остаются на месте. Закрытые API, платные ленты и кабинеты не подключены.

## Проверка и эксплуатация

Проверенные публичные RSS вернули HTTPS 200 с обычной проверкой сертификата;
robots разрешал выбранные feed-пути. На сохранённых во временную папку ответах:
ЦБ — 14 публикаций с описанием, Интерфакс — 25 (4 экономических), Frank Media —
60 с описанием. Тексты издателей не добавлены в тестовые fixtures репозитория.

Миграции запускаются штатным Go server/worker. Посмотреть фактическую настройку
сбора в нужной БД можно запросом:

```sql
SELECT id, enabled, adapter, config->>'feed_url' AS feed_url,
       config->>'source_class' AS source_class, config->>'priority' AS priority
FROM sources WHERE enabled AND adapter IS NOT NULL ORDER BY priority, id;
```

На чистой установке результат — S077, S136, S142. Существующие пользовательские
источники миграция намеренно не отключает. Смена `enabled` действует на будущий
сбор; уже поставленные задания не теряются. Для возврата расширенного старого
набора оператор может снова включить нужные ID из миграции `0003_news_rankings`.

Автотесты используют искусственные RSS, подставной ranker и временный PostgreSQL:
проверяют конфигурацию, фильтры, безопасность URL, повторный импорт без дублей,
продолжение работы после отказа одного источника и появление карточек в Go-ленте.
В итоговом локальном прогоне `go test -race ./... -count=1 -v` прошли 69 тестов
(120 с учётом подслучаев), без пропусков; `go vet ./...` также прошёл. Текущий
`RSSFetcher` с конфигурацией из миграции разобрал сохранённые реальные ответы:
14 / 4 / 60 публикаций; все с URL, ID, заголовком, описанием и исходной датой,
60 материалов Frank Media также с RSS body. Отдельная проверка обновления БД
с прежних миграций сохранила контрольную историческую новость с body и
пользовательский источник с его конфигурацией.
`govulncheck` не нашёл достижимых уязвимостей или уязвимостей в импортируемых
пакетах. На уровне модуля есть [GO-2026-5932](https://pkg.go.dev/vuln/GO-2026-5932)
для `x/crypto/openpgp`; этот пакет проект не импортирует. Зависимости в задаче
не менялись; при добавлении OpenPGP эта оценка неприменима.
Это не проверка реальных ответов LLM или работающего кластера. RSS-сборщик не
перепроверяет robots на каждом цикле; при изменении правил доступа источник
следует отключить и пересмотреть условия.
