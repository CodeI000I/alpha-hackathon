## Подключение

OpenAI-compatible API для Python и совместимых приложений:

- Основной Base URL: https://changellenge.up.railway.app/v1
- Запасной Base URL для российских хостингов: https://api.alfahack-gateway26.ru/v1
- Командный ключ хранится только локально в `.local-context/.env.llm`, переменная
  `HACKATHON_LLM_API_KEY`. Файл исключён из Git и Docker build context, права 0600.
  Содержимое не копировать в документацию, Graphify, логи или браузерный код.
- Файл автоматически приложением не загружается. Это сохранённая конфигурация,
  а не уже подключённый клиент. Автоматическое переключение endpoint не реализовано.

## Общий бюджет команды

500 рублей в день на один ключ, суммарно для всех участников и всех моделей.
При ошибке `Budget has been exceeded` дождаться сброса в **03:00 МСК**.
Это инструкция организаторов, не измерение расхода и не локально реализованный лимит.

Не публиковать ключ в открытых репозиториях и чатах и не размещать его в браузерном
коде. При проблемах передать организаторам название ключа и текст ошибки, не сам ключ.

## Пример организаторов с ключом из окружения

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["HACKATHON_LLM_API_KEY"],
    base_url=os.environ["HACKATHON_LLM_BASE_URL"],
)
response = client.chat.completions.create(
    model="deepseek/deepseek-v4.1-flash",
    messages=[{
        "role": "user",
        "content": "Предложи структуру анализа новости: основное событие, "
                   "затронутые компании, возможные риски и возможности.",
    }],
)
print(response.choices[0].message.content)
```
