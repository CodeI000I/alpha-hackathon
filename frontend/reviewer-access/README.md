## Как войти

1. Откройте ссылку входа выше.
2. Скопируйте почту и пароль из одной строки таблицы, без обратных кавычек и пробелов.
3. Нажмите «Войти».
4. В личном кабинете проверьте компанию и роль.
5. Для другого аккаунта сначала нажмите «Выйти». При необходимости используйте отдельное окно инкогнито.
6. По каждому аккаунту в таблице компания уже создана. Не регистрируйте её повторно.

Старые `finance@signal.demo` и `operations@signal.demo` — другой набор, только для автономного frontend demo. Для опубликованного сайта используйте таблицу выше.

## Что показала проверка 26 октября 2026

У каждой из четырёх компаний заполнен профиль и загружено по четыре документа. Однако при проверке ленты были пустыми, часть документов имела ошибку анализа `invalid_response`, а аналитика РЖД возвращала HTTP 503. **Рабочий вход не означает, что весь аналитический сценарий готов.** Подробности и идентификаторы — в [результатах проверки](./VERIFICATION_RU.md).

Чтобы отдельно проверить создание своего профиля, используйте [инструкцию регистрации](./REGISTRATION_RU.md).

Полный маршрут проверки из PDF — [событие → бизнес-ситуация → чат → график → восстановление состояния](./DEMO_SCENARIO_RU.md). Это сценарий проверки, а не утверждение, что все шаги уже успешно пройдены на стенде.
